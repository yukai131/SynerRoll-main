# BUG-007：边界日期与能流展示规则不统一

> 修复日期：2026-10-04
> 状态：已定位、已修复、待回归验证
> 严重程度：P1 — 日期入口和能流明细存在语义、可读性及一致性问题
> 影响范围：边界导入、任务结果导航、能流平衡分析、设备颜色与运行明细

---

## 1. 问题描述

**用户操作路径**：

1. 进入边界配置页，导入没有日期列的 CSV 时序数据
2. 在“日期语义”中看到“仅按时长”和“绑定日期”两个入口，并阅读额外说明
3. 创建并打开仿真任务，进入结果分析和能流平衡分析
4. 在不同结果图中对比同一种设备的颜色和源荷构成

**预期行为**：所有边界统一绑定自然日期；没有日期时默认从 2026-01-01 开始。结果导航不再显示未使用的碳排放分析。能流主图文字清晰，正刻度以红色表示源、负刻度以蓝色表示荷；设备颜色在全软件保持稳定。源荷占比只在点击“查看明细”后，以两张环形图和补充指标表呈现。

**实际行为**：边界仍允许选择“仅按时长”，日期说明占据额外空间；结果导航保留碳排放分析占位入口；能流页说明文字和图表字号偏小，右侧纵向占比条压缩主图；不同图表各自按数组顺序分配颜色，同一设备可能变色，也没有集中展示弃风、弃光等明细。

### 2.4 分析与排除

**H1 被确认**：日期模式同时存在于表单选项、请求字段、SQLite 默认值和历史配置读取逻辑中，单独隐藏下拉框不能保证后端与旧数据统一。

**H2 被确认**：碳排放分析只有 `sections` 中的导航项，内容落入统一“开发中”占位，没有独立数据链路，因此删除导航项不会影响已有计算结果。

**H3 被确认**：源荷占比条以固定宽度 `w-36` 与主图并排，必然压缩绘图区。

**H4 被确认**：能流、设备出力、灵活性贡献分别依据数组位置取色，数据顺序或筛选变化会导致颜色变化。

## 3. 根因确认

问题根因是日期语义和设备视觉语义没有唯一来源：边界双模式分散在前端、BFF/Julia 和 SQLite 默认值中；设备颜色则由每个图表组件临时决定。能流明细同时采用固定侧栏，造成信息密度高但主图可读性低。直接证据分别位于 `app/pages/boundary/[projectId].vue:133`、`backend/services/boundary_service.jl:117` 和原三个图表私有色板位置。

---

## 4. 修复方案

### 4.1 统一边界日历语义

前端固定显示“绑定日期”，默认首日集中为常量：

```typescript
export const DEFAULT_BOUNDARY_START_DATE = '2026-01-01'
export type BoundaryTimeMode = 'calendar'
```

Julia 新导入固定为 `calendar`；`boundary_config` 历史记录在建表检查时向前迁移，缺失日期补为 2026-01-01，并根据 `day_count` 推导终止日。任务页读取旧项目元信息时执行同样的日期范围归一化。

### 4.2 删除占位结果入口

从 `app/pages/tasks/index.vue:62` 的 `sections` 中移除 `carbon`，不删除组件库中的碳介质和碳总线定义，避免把“结果导航删除”扩大为模型能力删除。

### 4.3 重构能流展示与明细

- 删除页内说明区和右侧纵向占比条；
- 主图标题、图例、坐标文字提升至 11–16px；
- y 轴正刻度使用红色 rich text，负刻度使用蓝色 rich text；
- 每张能流图右上角增加“查看明细/收起明细”；
- 展开后显示源、荷两张环形图，中心分别显示放大的“源”和“荷”；
- 下方表格最初汇总弃风、弃光、供能缺额和能量过剩；该版式后续由 BUG-010 调整为源/荷设备累计电量与占比明细。

环形图与表格均从主图使用的 `liveData` 和相同时间窗口计算，不引入第二套结果真值。

### 4.4 固定设备颜色

`config/device-colors.ts:7` 成为设备颜色唯一来源，提供已知设备映射和稳定哈希兜底。画布默认外观、能流图、设备出力图和灵活性贡献图统一调用共享取色函数，筛选、排序或切换模式不再改变设备颜色。能流图额外通过固定方向色区分储能充/放电和电网购/售电，并在主图、图例与环形图中复用相同映射。

## 5. 预期结果与副作用

| 指标 | 修复前 | 预期修复后 |
|---|---|---|
| 边界日期模式 | 可选仅按时长或绑定日期 | 只保留绑定日期 |
| 无日期 CSV 首日 | 依赖用户选择或为空 | 默认 2026-01-01 |
| 碳排放结果入口 | 显示占位模块 | 不再显示 |
| 能流主图宽度 | 被右侧占比条压缩 | 使用完整卡片宽度 |
| 源荷色义 | 刻度同色 | 正值红色、负值蓝色 |
| 设备颜色 | 随图表和数组顺序变化 | 按设备类型固定 |
| 构成明细 | 始终显示纵向占比条 | 点击后显示双环形图和指标表 |

**副作用与风险**：

- 24 小时典型日也会被解释为 2026-01-01 当天，这是统一日期语义后的预期行为。
- 读取历史 `duration_only` 配置会触发 SQLite 向前迁移并补日期；迁移只补时间元信息，不改写时序值。
- 同一设备类型的多个实例共享颜色，图例通过设备名称区分；未知设备使用稳定 key 兜底。
- 弃风、弃光表格依赖任务结果中存在 `E_WT_cut`、`E_PV_cut` 系列；不存在时显示 0，而不是推测值。
- 完整 Nitro 打包仍受本机 `readlink EPERM` 权限限制，客户端和服务端 Vite 编译已通过。
