# SynerRoll 使用说明（Windows 便携版）

综合能源优化建模与计算工作台 —— 解压即用，无需安装开发环境。

---

## 快速开始

1. **解压** `SynerRoll-win64.zip` 到任意目录（建议路径不含中文和空格）
2. **双击** `启动 SynerRoll.bat`
3. 首次启动约 **20–40 秒**（Julia 计算引擎加载），请等待启动画面消失
4. 主界面自动打开，即可开始建模与计算

> 系统要求：Windows 10/11 x64 · 内存 ≥ 8 GB（推荐 16 GB）· 磁盘 ≥ 3 GB

### 其他启动方式

| 方式 | 说明 |
|---|---|
| `启动 SynerRoll.bat` | 标准启动（Electron 图形界面） |
| `启动-命令行模式.bat` | 图形界面异常时的备用方式 |
| `停止服务.bat` | 停止所有后台进程 |
| `导出诊断日志.bat` | 打包日志用于技术支持 |

## 目录结构

```
SynerRoll/
├── SynerRoll.exe          启动器
├── config/
│   └── synerroll.json     运行配置（端口、求解器、目录）
├── app/
│   ├── .output/           Web 应用服务
│   ├── backend/           计算引擎（Julia）
│   ├── config/            组件库
│   └── templates/         容量规划模板
├── runtime/
│   ├── julia/             Julia 运行时
│   └── julia-depot/       Julia 依赖
├── data/                  用户数据（项目、任务、结果）
├── logs/                  运行日志
└── resources/             图标等资源
```

**`data/` 目录请定期备份**，包含您的全部项目与计算结果。

## 配置说明

编辑 `config/synerroll.json`：

| 字段 | 默认 | 说明 |
|---|---|---|
| `juliaPort` | 8080 | 计算引擎端口（占用时自动 +1） |
| `bffPort` | 3000 | 应用服务端口（占用时自动 +1） |
| `solver` | `"HiGHS"` | 默认求解器：`HiGHS`（免费）或 `COPT`（需许可） |
| `dataDir` | `"data"` | 数据目录 |
| `logDir` | `"logs"` | 日志目录 |
| `julia.heapSizeHintMB` | 0 | Julia 内存上限（MB），0 = 不限 |
| `julia.startupTimeoutSec` | 120 | 计算引擎启动超时 |

修改后**重启 SynerRoll 生效**。

## 求解器

### HiGHS（默认）

- 开源免费，开箱即用
- 支持 LP / MILP
- 大规模混合整数问题可能较慢

### COPT（可选）

- 商业求解器，性能更强
- **需自备许可证**，本产品不随包分发
- 许可文件放到 `data/licenses/copt/`，或将环境变量 `COPT_LICENSE_DIR` 指向许可目录
- 在配置中设置 `"solver": "COPT"`
- 若许可无效，系统会提示并可回退 HiGHS

## 托盘菜单

右下角托盘图标：

- **打开 SynerRoll** — 显示主窗口
- **查看日志** — 打开日志目录
- **重启计算引擎** — 不重启整个应用，仅重启 Julia
- **退出** — 完全退出（关闭窗口只是最小化到托盘）

## 故障排查

### 启动很慢 / 一直停在启动画面

- 首次启动需加载 Julia 计算引擎，15–40 秒属正常
- 超过 2 分钟未就绪：查看 `logs/launcher.log` 和 `logs/julia.log`
- 杀毒软件可能拦截 Julia 进程，尝试加入白名单

### 端口被占用

- 启动器会自动尝试后续端口
- 如需固定端口：修改 `config/synerroll.json` 中的 `juliaPort` / `bffPort`
- 也可用命令行检查：`netstat -ano | findstr :8080`

### 求解器报错

| 现象 | 处理 |
|---|---|
| COPT license 错误 | 安装 COPT 许可，或改用 `"solver": "HiGHS"` |
| 求解超时 | 减小仿真时间范围 / 时间分辨率，或换更强求解器 |
| 模型不可行 | 检查边界数据覆盖、组件参数、拓扑连接 |

### 界面打不开 / 白屏

1. 确认 `app\.output\` 目录完整
2. 打开 `logs\bff.log` 查看错误
3. 尝试手动访问 `http://127.0.0.1:3000/`（端口以实际为准）

### 端口自动递增后前端连不上

- 查看 `logs/launcher.log` 中的 `ports:` 行确认实际端口
- 重启应用让前端重新读取

## 数据备份与迁移

**备份**：复制整个 `data/` 目录。

**迁移**：将 `data/` 复制到新机器的同名目录，或修改配置中的 `dataDir`。

**卸载**：直接删除安装目录即可；`data/` 如需保留请先备份。

---

## 内网 / 离线部署

- 默认绑定 `127.0.0.1`，仅本机访问
- 如需局域网访问，将 `host` 改为 `"0.0.0.0"` 并确保防火墙放行
- **完全离线可用**，无需互联网连接

---

## 日志

| 文件 | 内容 |
|---|---|
| `logs/launcher.log` | 启动器：进程拉起、端口、健康检查 |
| `logs/julia.log` | 计算引擎输出 |
| `logs/bff.log` | 应用服务输出 |

反馈问题时请附上以上日志（可打包整个 `logs/` 目录）。

---

## 常见限制

- 当前为单机版，不支持多用户并发编辑同一项目
- 离线任务不支持暂停/恢复（取消后需重建）
- 经济全生命周期评价部分功能仍在完善中
- COPT 许可与分发请遵守厂商条款
