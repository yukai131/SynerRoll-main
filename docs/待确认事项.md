2. 普通仿真采用独立 Julia 工作进程，保留现有单层、多层、在线、离线业务；取消可直接停止任务进程。

4. 容量规划预算不含进程启动和 Julia 编译。预算在工作进程内使用扣除编译耗时的时钟；原生场景求解使用剩余预算。
5. 设备特殊校验入口保留，恢复原有 validation.jl，业务规则由项目方后续补充。
6. 正式名称“新能源发电系统灵活性量化评估软件”，内部文件标识 PSFA，发布单位龙源（北京）新能源工程技术有限公司，英文 longyuan，正式版本 1.0.0。品牌字段位于 config/brand.json，填写指引见 docs/品牌信息填写.md。

8. 单层、多层仿真均须正常开展灵活性业务。修复单层遗漏时段评价和汇总；单层评价使用已求解的目标层。
