## 2. 数据来源与口径

- 比较数据**全部来自 `planning_evaluations` 落库的 breakdown**，不重新计算：
  - 运行成本 = `weightedOperatingCost ÷ 1e4`（万元，Σ 场景成本 × weightDays）；
  - 初始投资 = `(lifecycleCapexWan + lifecycleConstructionVatWan)`（万元，同 C-404 `initial-investment-min` 口径）；
  - NPV/IRR/LCOE = `indicators`（C-403 全投资税后口径）；IRR 展示为 %；
  - 回收期 = `lifecyclePaybackYears` / `lifecycleDiscountedPaybackYears`（NaN/缺失 → null）；
  - 现金流 = breakdown 新增 `lifecycleAfterTaxCashflowWan`（逐年税后净现金流，万元，下标 0=建设年，C-405 起随评价留痕）；
  - 场景贡献 = breakdown `scenarioCost:<scenarioId>`。
- 基准 = 可行候选中排名第 1 者（与 `bestEvaluationId` 同口径）。
- 旧任务（C-405 前跑出的评价）无现金流留痕 → 展开行显示「无现金流留痕」，其余指标正常。

## 3. 近似与遗留（评审输入）

1. **碳/可靠性/灵活性未接线**：待 F 线仿真后验指标层（与 C-404 技术约束同一层），接线前以 null 占位、展示「待 F 线」。
2. **敏感性为静态排名矩阵**：反映排序对目标/指标选择的敏感程度，非参数扰动重算（参数敏感性需重跑评价，属 C-406+ 范畴）。
3. 多指标排名矩阵把 fitness 本身也列为一列，便于和单指标排名对照。
