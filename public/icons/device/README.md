# 图标资源说明

你只需要替换本目录下的 PNG 文件，**文件名保持不变**即可。

## 规格建议

- 正方形，主体居中
- 建议 ≥512×512
- 透明底或统一浅色纯色底
- 风格尽量统一（光比、裁切、色调）
- 不要烧字 / 水印
