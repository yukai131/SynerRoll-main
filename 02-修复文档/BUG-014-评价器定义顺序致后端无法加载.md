> 下方保留来源问题的日志、日期、代码行号和当时验证状态；主版本融合实现与验证以[容量规划融合记录](../docs/容量规划融合记录-2026-10-19.md)为准，本次未重跑。

> 严重程度：P0 — 后端整体 LoadError，容量规划全部功能不可用

## 1. 问题描述

**用户操作路径**：

1. 开发机上启动 Julia 后端（`backend/server.jl`）
2. include 到 `services/capacity_planning/economic_evaluator.jl` 时进程退出

**预期行为**：后端正常起服，`/health` 可访问。

**实际行为**：

```
ERROR: LoadError: UndefVarError: `TimeseriesOperatingCostEvaluator` not defined in `Main`
Stacktrace:
 [1] top-level scope
   @ ...\backend\services\capacity_planning\economic_evaluator.jl:57
```

## 2. 定位过程

### 2.1 初始假设

| 编号 | 假设 | 对应症状 | 初始置信度 |
|---|---|---|---|
| H1 | `TimeseriesOperatingCostEvaluator` 的 struct 定义在该文件第 57 行**之后**，方法签名即时求值时类型尚不存在 | 报错行恰为方法签名行，UndefVarError 指类型未定义 | ⭐⭐⭐⭐⭐ |
| H2 | struct 定义在别的 include 文件中且顺序不对 | 同上可能 | ⭐⭐ |
| H3 | 拼写不一致（大小写/全半角） | UndefVarError 也可能由拼写引起 | ⭐ |

### 2.2 验证方案

本问题属于**加载顺序类**，静态阅读即可证实，无需插桩日志：读取 `economic_evaluator.jl` 全文，核对每个"方法签名中引用的具体类型"的定义位置。

### 2.3 验证结果（静态阅读摘录）

- 报错行（修改前 `economic_evaluator.jl:57`）：

```julia
economic_evaluator_version(::TimeseriesOperatingCostEvaluator) = TIMESERIES_OPERATING_COST_EVALUATOR_VERSION
```

- 同文件 struct 定义位置（修改前 `:160`）：

```julia
struct TimeseriesOperatingCostEvaluator <: AbstractEconomicEvaluator end
```

- 第 48 行函数体内同样引用该类型但不报错（函数体惰性求值，运行时类型已定义）。

### 2.4 分析与排除

**H1 被确认**：Julia 顶层顺序求值，给具体类型追加方法的签名在**执行到该行时立即解析类型**；第 57 行执行时第 160 行的 struct 尚未求值，必现 UndefVarError。

**H2 被排除**：全仓库 grep 确认该 struct 仅定义于 `economic_evaluator.jl` 一处；`server.jl` include 顺序（types → … → economic_evaluator）中 `AbstractEconomicEvaluator` 等基类型均已在先。

**H3 被排除**：两处标识符逐字符一致。

## 3. 根因确认

C-404 修改 `economic_evaluator.jl` 时重写了 `TimeseriesOperatingCostEvaluator` 的 docstring 与 struct 块并置于文件后半段（原位置在该文件前部、第 57 行方法签名之前），旧的靠前定义被删除，导致"方法签名（`:57`）先于 struct 定义（`:160`）执行"。C-404 之后该后端从未加载成功，本次为 C-404 后首次启动暴露。

## 4. 修复方案

将 docstring + struct 块整体移动到 `economic_evaluator_from_config` 之前、两个 `economic_evaluator_version` 方法签名之前（修改后位于 `:55-67`，方法签名在 `:70-71`），文件其余内容不动。函数体内引用（如 `:48`、`:231` 的 `evaluate_economics` 特化）本就惰性求值，无需调整。

## 5. 预期结果与副作用

| 指标 | 修复前 | 预期修复后 |
|---|---|---|
| 后端启动 | LoadError 退出 | 正常起服，`/health` 通 |
| 候选经济评价 | 不可用 | 恢复 C-404 行为 |

**副作用**：无行为变化（仅声明位置移动）；已顺手扫描同目录其余 Julia 文件（lifecycle_economics / comparison_summary / optimization_runner / planning_manager），无同类"签名先于定义"隐患。
