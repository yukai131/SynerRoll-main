## 2. 重复与合并结论

- 能流：原主目录 BUG-003、BUG-007 的能流展示、BUG-010 和 BUG-019 的氢/热跟踪合入 BUG-003；早期侧栏和补充指标表被后续构成明细替代。
- 日期：原主目录 BUG-006 与 BUG-007 的日期部分合入 BUG-006；双模式仅保留为历史说明，当前统一 calendar。
- 时间控件：原主目录 BUG-008、BUG-011、BUG-012 合入 BUG-007；原 BUG-019 的全年滑动性能诊断也归此，明确未优化。
- 设备视觉：原主目录 BUG-013～016 与 BUG-007 的公共设备色合入 BUG-009；按设备色相、时层深浅、变量线型、图例统一描述，保留 22px → 36px 的方案演进。
- 其他交互：原主目录 BUG-019 的经济提示、拟合 loading、设备台数入口，与 BUG-007 的占位导航清理归入 BUG-012。
- 容量规划 4 份与外层根因不重复，分别保留为 BUG-013～016。评价器加载顺序与典型日统计虽涉及同一文件，分别是加载期和费用区间问题；工作目录锁与取消控制分别是清理和计算控制问题，不因同模块而合并。
- 原 BUG-004 的方向映射与 BUG-005 的分时贡献聚合是不同问题，保留独立文档并交叉引用；边界大数组、时间正则和日期绑定也分别涉及存储、解析及日期契约，不合并。
