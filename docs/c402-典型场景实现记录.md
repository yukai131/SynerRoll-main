## 2. 数据质量检查（reducer §4）

- **缺测（4a）**：任一边界当天缺失比例（NaN 计数）> missingDayThreshold 即剔除该天，原因记入 `quality.excludedDays`；剔除后无可用天则报错。
- **缺失填充（4b）**：阈值允许的部分缺失天，剩余 NaN 按该边界整体均值填充，填充点数入 `quality.nanFilledPoints`。
- **重复（4c）**：全部边界日曲线拼接哈希，完全重复日只告警不排除（可能为真实重复天气），计数入 `quality.duplicateDayCount`。
- **异常（4d）**：各边界日总量 z-score，|z|>6 告警保留，计数入 `quality.anomalyDayCount`。
- 时区/时间步：metadata.timezone（Asia/Shanghai）与 resolutionMinutes（60）随场景集输出；单位经 series 元数据透传。

## 3. 极端日保留（reducer §5）

- 识别规则（boundary var_name/meaning 小写匹配）：负荷组 `load|负荷`，可再生组 `wind|solar|irr|风|光|辐照`。
- 峰荷日 = 负荷组日总量 argmax；低可再生日 = 可再生组日总量 argmin；两天去重后从聚类池剔除。
- 保留日各自成场景：`weightDays=1`、`preserved=true`，与聚类场景一并按日期排序编号。
- 聚类 clusterCount 只作用于剩余池；池不足时降档并告警。
- 组特征未识别到时给警告跳过（不静默）。
