## 2. 实现细节

### 2.1 组件 schema 声明（component-library.json，均为可选键）

```json
"planning": {
  "optimizable": true,
  "valueKind": "integer",          // continuous（默认）/ integer / tier
  "tiers": [1000, 2000, 5000],     // valueKind=tier 必填，严格递增
  "minAdded": 0, "maxAdded": 2000, // 新增量上下界（相对现有容量）
  "groupId": "storage-pv", "groupRatio": 1.0,   // 成组（成员各自声明，比例联动）
  "mutexGroup": "方案A"             // 互斥组
}
```

schema 声明非法（tier 非递增、成组少于 2 成员、minAdded>maxAdded 等）在 detect 阶段直接报错。

### 2.2 变量表单（schemaVersion → capacity-variable-form-v2）

`detect_capacity_variables` 输出增加 `valueKind/tiers/minAdded/maxAdded/groupId/groupRatio/mutexGroup`；tier 型边界默认取首尾档位，integer 型缺省 step=1。v1 客户端提交的旧字段仍可校验通过（新字段由服务端权威生成，前端提交值仅校验一致性）。

### 2.3 服务端校验（validate_capacity_variables）

- 身份一致性：componentKey/parameterPath/unit/**valueKind**；
- `min ≤ initial ≤ max`：现有容量超出 schema 声明范围即拒绝；
- 形态校验：integer 的 fixedValue/lowerBound/upperBound/suggestedValue 必须为整数；tier 必须落在档位集合内；
- 新增量：lowerBound ≥ current+minAdded、upperBound ≤ current+maxAdded；
- 互斥：同 mutexGroup 至多一个 mode=optimize。

### 2.4 优化循环（optimization_runner.jl）

- `_quantize_candidate`：integer 取整 + clamp；tier 吸附最近档位 + clamp；continuous 维持原 step 量化；
- `_variable_constraint_violation`（新）：互斥——同组多于一个变量（含 fixed）偏离现有容量即违约；成组——以组内 ratio 最大者为基准，`v_i = v_base × ratio_i/ratio_base`，容差 = 成员 step/2 与相对 1e-6 的较大者；
- 违约候选直接返回 failure_penalty（记失败，不进缓存）。

## 3. 近似与遗留（评审输入）

1. **成组/互斥为后验拒绝**：BlackBoxOptim 只支持盒约束，比例/互斥约束在量化后校验，违约候选浪费评价次数。若某任务大量候选违约，应升级优化器（C-404 多目标时一并评估 DE 约束处理或惩罚函数法）。
2. **互斥语义**：定义为"同组至多一个变量偏离现有容量"（选择型互斥）；若业务需要"允许都偏离但限总量"之类语义，需另议。
3. **成组基准**：取 ratio 最大者为基准；建议业务配置时把"主设备"设为最大 ratio。
4. **容量四分类**：替换/退役需改变 candidate snapshot 语义（退役=移出模型/置零、替换=旧设备残值+新设备投资），与 C-403 现金流联动，放第二增量。

## 6. 量化网格修正（2026-09-28，配合 BUG-006）

**背景**：连续变量的 step 吸附原来锚在 `lowerBound` 上（`lower + round((n-lower)/step)*step`），而下界 = 当前容量 × 系数（如 44875×0.5=22437.5），导致全部候选容量带 .5 尾数；在组件字段被推断为 Int64 的环境中直接触发 `InexactError`（BUG-006）。

**改动**（`optimization_runner.jl` `_quantize_candidate`）：
- 连续变量（有 step）：吸附到 **step 的整数倍网格（0 对齐）**，界内网格点存在时（`ceil(lower/step) ≤ floor(upper/step)`）候选恒为整数且自动满足上下界；界内无网格点时回退为原样 clamp。
- integer 变量：吸附到 `ceil(lower)`~`floor(upper)` 的界内整数网格，避免 clamp 回带小数的界。

**影响**：候选值分布从"下界对齐"变为"0 对齐"，如 step=1000、界 [22437.5, 89750] 时候选 ∈ {30000, 31000, …, 89000}；下界附近的 22437.5 不再可达（最低 30000）。结果页候选/应用后的容量均为整数。
