## 1. 问题描述

经济性扇形图悬停无提示；风机或光伏“拟合计算”请求未返回时没有加载反馈；所有组件参数面板仍显示需删除的“设备台数”。另有“碳排放分析”结果导航仅为未实现占位。

预期：经济图显示名称、金额、占比；拟合复用气象导入/提交的 AppButton loading；全部组件移除设备台数入口；删除占位导航。

## 2. 定位过程与历史验证

源代码确认：PieChart 的 SVG path 无 pointer 事件和提示容器；拟合 runFit 已维护 fittingLoading，按钮未绑定；deviceCount 控件由统一属性面板无条件渲染。碳排放分析只有 sections 导航项，内容落入“开发中”占位。

2026-10-20 原验证包含真实全年经济页、临时隔离拟合页及实际编辑器。经济提示显示“风机 - 运维成本 / 39,479,686.15 元 / 占比：18.4%”；wind 成功与 pv 失败两条受控 Promise 路径均检查 loading、按钮禁用和请求结束恢复，一次点击仅增加一次请求。实际电化学储能属性面板不再显示设备台数。临时拟合页未读写项目，验证后删除。

## 3. 根因确认

交互所需数据和异步状态已经存在，但显示组件未消费；设备台数入口统一定义导致多类设备重复出现；结果导航配置未随未实现模块清理。

## 4. 修复方案

1. PieChart 为扇区及图例增加 pointer 提示，显示名称、数值、单位、占比。提示 Teleport 到 body 并 fixed 定位，避免滚动容器裁切；离开或输入项变化时隐藏。经济页传 unit="元"，占比沿用绝对金额口径。单项整圆使用两段 SVG 弧，确保有可命中扇区。
2. 拟合按钮绑定 :loading="fittingLoading"、loading-label="拟合中..."，请求期间禁用提交；复用现有 try/finally 与重复调用保护。
3. 删除基础信息中的设备台数行及更新函数，覆盖全部共用面板组件；保留历史 deviceCount 字段，不迁移或清空项目。
4. 删除结果 sections 中的 carbon 占位项；组件库碳介质与碳总线定义保留，不扩大为删除建模能力。

## 5. 预期结果与副作用

经济图有金额/占比提示；拟合等待有旋转反馈，成功/失败后恢复；参数面板不再提供台数编辑；结果导航无未实现碳排放入口。没有后端、数据库结构或物理公式变更，旧 JSON 仍可含 deviceCount。

本记录的历史验证仅覆盖上述修复，不将后续的饼图放大、画布宽高或任务预览移除等改动自动视为已验证。
