# 品牌维护

正式名称为“新能源发电系统灵活性量化评估软件”，发布单位为“龙源（北京）新能源工程技术有限公司”，英文标识 longyuan，版本 1.0.0。统一在 config/brand.json 维护。

- displayName：软件、窗口、安装向导和快捷方式显示名称。
- productName：PSFA，安装包、可执行文件和用户数据目录使用的稳定标识。
- publisher / publisherEnglish：中文发布单位与英文标识。
- version：发布版本。
- description：软件简介。

图标源文件位于 packaging/resources/logo-source.jpeg；转换产物为 packaging/resources/icon.ico、public/logo.png、public/favicon.ico 及 packaging/electron/ui/logo.png。许可证页位于 packaging/electron/ui/license.html，来自项目方提供的旧软件样式；启动页采用相同配色。旧 Key 校验值位于 packaging/electron/license-keys.json，每次启动本地验证，不保存明文 Key。

修改后重新构建。发布单位文字不等同于 Windows 数字签名；当前未提供签名证书。内部应用标识保持稳定，用于安装识别，不跟随版本变化。
