## 2. 公式实现对照

单位：内部万元，边界元（×10⁴）。实现文件 `backend/services/capacity_planning/lifecycle_economics.jl`。

| 项 | Excel 公式 | 实现 |
|---|---|---|
| 设备原值 | 单位造价 × 装机（计算 sheet E 列） | `initial_cost`(元/kW) × 候选容量(kW) / 10⁴ |
| 年折旧 | 原值 × (1−残值率) / 折旧年限（计算 sheet S 列） | 直线折旧；年限取 `depreciation_year` 缺省 `life_year`；各设备按自身年限折旧 |
| 残值率 | 发电/储能 5%，电解槽/储氢 3%（计算 sheet R 列） | 默认 5%，ELY/HS 覆盖 3%（`LIFECYCLE_SALVAGE_OVERRIDES`，若 HS 为热储能需调整） |
| 建设投资增值税 | 设备投资 × 10%（投资测算 F4） | `construction_vat_rate = 0.10` |
| 流动资金 | 装机 × 30 元/kW（计算 sheet K/L 列） | `working_capital_rate = 30` 元/kW，第 0 年流出、末年回收 |
| 销项税 | 营业收入 × 13%（收入税金表） | 售电收益视为含税 → 不含税收入 = 含税 / 1.13 |
| 成本进项 | （材料+燃料等）× 13%（收入税金表） | 经营成本 × 13% × 可抵扣比例（参数 `input_vat_deductible_ratio`，默认 1.0，近似） |
| 应缴增值税 | max(0, 销项 − 进项 − 留抵结转) | 留抵期初 = 建设投资增值税，逐年结转 |
| 营业税金及附加 | 增值税 × 12%（城建 7% + 教育附加 5%，IRR 表） | `surcharge_rate = 0.12`（冲突见 §4） |
| 调整所得税 | EBIT × 税率（现金流量表），三免三减半（利润表） | max(0, EBIT) × 有效税率；EBIT = 不含税收入 − 经营成本 − 附加税 − 折旧；第 1-3 年 0、4-6 年减半、之后全率（15%） |
| 末年回收 | 回收固定资产余值 + 回收流动资金（现金流量表） | Σ原值 × 残值率 + 流动资金 |
| NPV | Σ cf_t / (1+r)^t，t=0..n | 折现率默认 8%、n=20，可配 |
| IRR | Excel IRR() 迭代 | [-0.99, 10] 二分 200 轮；不变号返回 nothing + reason，不填占位数字 |
| 回收期 | 累计（折现）现金流首次转正 | 年内线性插值；恒负返回 nothing |
| LCOE | 生命周期总成本现值 / 折现电量 | 折现成本（CAPEX+增值税+流动资金+经营成本+进项+增值税+附加+调整所得税）÷ 折现上网电量；缺电量返回 nothing |

## 3. 输入来源与年化口径

- **CAPEX**：候选快照 `commonEconomicParams.initial_cost` × `apply_capacity_candidate` 返回的候选容量（ELOAD/HLOAD/QLOAD/GRID/BUS 不计）。缺字段进 warnings，不抛错。
- **年化**：典型场景日值 × 365 / weightDays。经营成本 = 场景总成本 + 售电收益（收益为负），含松弛惩罚——惩罚视为经营成本是近似，已在 warnings 留痕。
- **上网电量（LCOE 分母）**：CP/WT/PV/GP/CHP/ET 组件正功率 × 时层步长，年化同上。
- **配置覆盖**：economics config 的 `lifecycle` 子字典可按 snake_case 键覆盖全部财务参数。

## 4. 口径冲突与近似（评审输入）

1. **附加税率 12% vs 6%**：IRR 表 12%（城建 7% + 教育附加 5%），投资测算.xlsx 6%（1%+3%+2%）。实现取 12%，以完整现金流量表为准；可经 `surcharge_rate` 覆盖。→ c001 待确认事项 6。
2. **价税口径近似**：运行成本服务的售电收益按含税处理（价税分离 13%），经营成本按不含税全额计提进项。→ c001 待确认事项 7。
3. **财务费用**：全投资口径不扣利息（EBIT 口径），与 IRR 表一致；资本金/贷款结构不进现金流。
4. **摊销**：IRR 表经营成本扣无形/其他资产摊销，实现中摊销按 0 处理（组件参数无对应字段），折旧足额计入。
5. **设备替换**：折旧年限内不触发重购，替换投资现金流待 C-404。
