# BUG-009：设备出力配色、线型与图例展示

> 修复日期：2026-10-04、2026-10-05、2026-10-21  
> 文档整理：2026-10-21  
> 状态：已修复、待回归验证；保留原记录的验证范围  
> 严重程度：P2  
> 影响范围：设备出力多变量、多时层曲线及图例；公共设备颜色供画布和其他结果图复用

合并原主目录 BUG-013～016 及 BUG-007 的设备固定色部分。颜色、时层深浅、变量线型、图例布局是同一套识别规则的连续修正，统一维护；22px 图例标记是过渡值，最终为 36px。

## 1. 问题描述

用户在设备出力分析中选择同设备多个变量、多个时层：不同时层同色、不同变量同为实线，难以区分；选择更多项目后图例换行遮住纵轴名称和顶部刻度；即使曲线已有线型，默认图例的中心圆点和短线仍掩盖差异。跨图表按列表位置取色还会使同一种设备颜色漂移。

预期：设备固定色相、时层同色系深浅、变量稳定线型，图例准确反映曲线且不遮挡坐标。

## 2. 定位过程与历史验证

| 检查 | 结论 |
|---|---|
| 图表私有 PALETTE / CONTRIBUTION_COLORS | 各图独立按数组取色，跨页或筛选后颜色漂移 |
| DeviceOutputChart series 颜色 | 仅 getDeviceColor，layerId 未参与颜色计算 |
| series lineStyle | 仅颜色、宽度，缺少变量线型映射 |
| legend / grid | 普通图例自动换行，grid.top 固定 48px，不随行数扩展 |
| ECharts 6 LegendModel / LineSeries.getLegendIcon | 已默认继承线型；短线和中心 symbol 使差异不明显，不能误判为未继承 |

历史采用静态源码检查，未新增运行日志。2026-10-04～05 的前三阶段记录确认映射稳定、编译及空白检查通过；客户端和服务端 Vite 编译完成，Nitro 最终打包受本机用户目录 readlink EPERM 限制。原 BUG-016 的纯线段图例阶段没有独立运行验证记录，不能将其他阶段的构建结果扩写为其已验证。本次未重新验证。

## 3. 根因确认

视觉编码只覆盖设备维度，没有为时层和变量提供独立且稳定的映射。动态数量图例又使用固定单行绘图区间距；默认符号兼顾数据点，不适于表达多种划线节奏。

## 4. 修复方案与最终规则

### 4.1 统一设备基础色

config/device-colors.ts 为设备颜色唯一来源：已知类型固定映射，未知类型用稳定 key 哈希兜底。画布默认外观、运行总览、能流、设备出力和灵活性贡献共享取色函数。能流额外固定储能充/放和购/售电方向色，主图、图例、明细复用。

同类型多实例共享色相，通过设备名称区分；筛选、排序、模式切换不改变色相。旧的私有八色色板与按可见下标取色不再作为当前配色规则。

2026-10-21 补充方向色调整：能流图原电化学储能充电与气电机组均为 #F97316，现将充电改为深棕 #92400E；原储氢罐充/放氢与氢网购氢均为 #14B8A6，现新增储氢罐充氢蓝灰 #475569、放氢保留 #14B8A6，氢网购氢改为其基础色浅青绿 #2DD4BF。主图、图例、环形图及明细色块继续共用 getEnergyFlowColor，运行总览和设备出力基础色不变。按用户要求未运行测试、构建或界面验证。

### 4.2 时层使用同色系深浅

将总览算法提取为公共 getLayerColor，设备出力按时层数字稳定排序后调用。多时层使用 0.35 + 0.65 × layerIndex / (layerCount - 1) 的 RGBA 递进，单层使用完整不透明基础色。lineStyle、itemStyle 与色板采用同一结果，图例和提示标记一致。总览的视觉效果保持不变。

### 4.3 变量使用稳定线型

- 六种线型：实线、虚线、点线、点划线及两种扩展划线组合。
- 输出/电量优先实线，输入/可用量优先虚线，弃电/缺额/过剩及储量优先点线，最小/最大约束优先点划线。
- 同设备首选线型冲突时按固定表选择未占用样式。
- 按完整设备变量目录和稳定 key 排序分配，不按当前勾选顺序；同变量跨时层保持同线型。
- 不额外开启数据点符号。

### 4.4 图例布局与纯线段标记

保留 ECharts 原生 legend 的点击显隐及横向 scroll 分页。左右各留 24px，grid.top 从 48px 改为 64px。图例标记曾先由 18px 改为 22px，后续由六种线型对应的纯线段 SVG path 替代中心圆点，最终宽 36px、高 10px，颜色继承 series 时层色，节奏对应变量线型。

### 4.5 长时间轴标签重叠与单位切换刷新（2026-10-21）

用户在全年设备出力图中看到横轴日期叠成灰带；切换底部单位后，坐标和曲线未立即更新，拖动时间滑块后才变化。

静态定位确认：时间段模式的数值轴把 interval 固定为 60 分钟，使全年范围生成约 8760 个刻度。参考系统灵活性需求来源图的自动刻度方式，时间段模式不再指定固定 interval，设置 splitNumber=5，并以 hideOverlap=true 避免窄图或局部窗口的日期文字碰撞。时间点追溯仍保留原有 15/60 分钟间隔。

单位选择由父组件原地更新 chart.units[dimension]，子组件此前只监听 unitSelections 对象引用，没有监听内部字段，因此不会触发 ECharts setOption；滑块更新则触发另一路监听，才让新单位和换算后的数据出现在图上。现改为监听 axisGroups 计算结果，其构造直接读取每个维度选中的单位。单位变化后通过既有 nextTick(render) 同步更新纵轴名称、刻度及曲线数值，Tooltip 与已有 CSV 导出仍沿用同一单位选择和换算函数。

本次只修改设备出力图的刻度与刷新依赖，没有改动结果数据、换算系数或滑块范围。按用户要求未运行测试、构建或界面验证；前文历史编译结果不覆盖此次调整。

## 5. 预期结果与副作用

| 维度 | 修复前 | 修复后 |
|---|---|---|
| 设备 | 各图顺序色板 | 跨页固定色相 |
| 时层 | 完全同色 | 同色系由浅到深 |
| 变量 | 全实线 | 完整目录稳定线型 |
| 多图例 | 换行遮挡坐标 | 单行滚动分页 |
| 图例标记 | 短线加圆点 | 36px 纯线段表达线型 |

浅色时层对比度较低；同设备变量超过六个可能复用线型，需结合名称、Tooltip 识别。宽图例会减少单页条目数，通过分页查看。仅调整显示，不修改结果数据。

本文件不处理后来单独诊断的悬停淡化/消失现象；该问题没有在这些历史修复中被证明已解决，不能混同为时层透明度设计。
